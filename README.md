# CapitalAgents
A local multi-agent financial advisory system

### Local execution
Requires that llama-server from llamacpp (https://github.com/ggml-org/llama.cpp) to be installed onto 'PATH' system environment variable.
Edit `llm/llamacpp/llamacpp_args.py` to your own model paths and llamacpp arguments.

Store API keys inside a `.env` file on the project's root directory.
Supported: OPENROUTER_API_KEY, GROQ_API_KEY, FRED_API_KEY, ALPACA_API_KEY, ALPACA_API_SECRET
